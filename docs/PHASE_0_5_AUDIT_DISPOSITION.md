## Public claims and release erratum

The [README](../README.md), [changelog](../CHANGELOG.md), and [Cybersecurity Trust Domain guide](CYBERSECURITY_DOMAIN.md) describe the default checks as structural and place authentication at an independent trust boundary. The changelog retains its original version ordering and historical test record.

The existing [v10.1.0 GitHub Release description](https://github.com/dfeen87/AILEE-Trust-Layer/releases/tag/v10.1.0) requires a separate factual erratum. Its limitations section presents cryptographic verification of publisher evidence and caller mandates as needing further validation. The default paths do not perform that verification. The erratum should state what the default checks actually establish and preserve the exact-binding and hosted verification limitations. Its packaging result refers to the release candidate and should be labeled historical if current verification is discussed. The GitHub Release was left as published.
